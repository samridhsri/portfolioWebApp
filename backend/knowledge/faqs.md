### Q: What is KV caching?
**A:** KV caching stores previously computed attention Key-Value pairs during autoregressive generation.

Without caching:
- the model recomputes attention for all previous tokens every step

With caching:
- only the newest token needs fresh computation

This dramatically improves generation efficiency and reduces inference latency.

---

### Q: What is quantization?
**A:** Quantization reduces model precision to make inference faster and more memory efficient.

Example:
- FP32 → INT8

Benefits:
- smaller memory footprint
- faster inference
- lower hardware requirements

Tradeoff:
- slight accuracy loss in some cases
